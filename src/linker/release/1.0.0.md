# fas-ld 1.0.0 — Linux x86-64

Status: frozen candidate; final release acceptance pending.
This linker version is independent of Fas language versions.

The release supports the Linux x86-64 ELF subset frozen in
[SUPPORT.md](../SUPPORT.md). It links native Fas and GCC/Clang C objects,
regular/thin archives and shared libraries; emits static/dynamic executables,
PIE, documented CRT-relocated static PIE, shared libraries and partial objects.
It includes versioned symbol resolution, TLS/IFUNC support, section GC, unwind
metadata, explicit library discovery and bounded libc linker scripts.

The supported CLI is documented by `fas-ld --help` and the [feature matrix](../README.md).
Compiler drivers supply CRT/libc files and supported flags. The native executable
embeds the OCaml runtime; no OCaml installation or external linker is needed to
run fas-ld. Its binary archive records actual system-library requirements.

The release intentionally excludes LLVM/GCC LTO, arbitrary GNU linker scripts,
Windows, other architectures, general static TLS relaxation and unrestricted
GNU flag compatibility. Existing C++ exception/RTTI/lifecycle interoperability
is regression-covered without a full C++ ecosystem guarantee. Resource bounds,
output-publication behavior and supported defaults are part of SUPPORT.md.
Checksums and payload inventories are not signatures. No speed advantage over
LLD is claimed; optimization is the next workstream after release acceptance.

Before publication, the exact versioned source must pass the complete hosted
correctness, six-project, official GCC and fourteen-target fuzz selection;
source rebuilding and delivered-archive execution; native-Fas dynamic/static
acceptance; and longer follow-ups on the historical timeout inputs. The final
release includes an independent qualification report with immutable commit,
run links, binary/archive digests, durations and known limitations. Earlier
failed campaigns stay failed and unreproduced timeout causes stay unknown.

Install `bin/fas-ld` from the binary archive into a directory on PATH, or follow
[the source build/install instructions](../README.md). Verify `SHA256SUMS`
before extraction. Linker releases use `fas-ld-v1.0.0` and do not supersede the
Fas language's latest-release designation.
