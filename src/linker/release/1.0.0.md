# fas-ld 1.0.0 — Linux x86-64

Status: released. [Download](https://github.com/fas-language/fas/releases/tag/fas-ld-v1.0.0).

fas-ld 1.0.0 completes the documented Linux x86-64 ELF release scope. Linker versions are independent of Fas language versions.

Built and qualified from **`3cf2962665405578b7a32a35f25e810e2ff188d5`**. The source archive is the exact frozen candidate snapshot; the accompanying qualification report records its completed final acceptance.

- Native Fas and GCC/Clang C objects; regular/thin archives, partial linking, static/dynamic executables, PIE, documented static PIE, shared libraries, symbol versions, TLS and IFUNC within the published contract.
- Complete local suite: **3,792 compiler checks and 273 linker cases in 45 groups**, no skips.
- [Complete hosted matrix](https://github.com/fas-language/fas/actions/runs/42373970629): correctness and archive rebuilding, SQLite, zlib, Chibicc, generated semantic/scale tests, six popular C projects and **4,974 official GCC C executions per linker** using identical inputs.
- Fourteen hosted fuzz targets at **600 seconds each**, **5,576,675 executions**, no saved crashes or hangs.
- Three final **one-hour campaigns**, **9,322,450 executions**, no saved crashes or hangs. The two historical timeout inputs and repaired descriptor-crash input each pass 1,000 direct replays and are imported into the relevant campaign. The historical timeout causes remain unknown; original failed campaigns remain failed.
- Four original native Fas Sieve sources pass **24 dynamic/static executions** through Fas, GNU and the native driver. Bounded Doom/Wolf3D rendering matches GNU.
- Latest independent MIR backend `984de64` passes **124 executions** through the delivered linker and GNU on identical objects: DWARF 5 verification, native TLS, hosted PIE/EXEC and native RELA static-PIE startup. A test-only object-export hook exposes the producer's existing startup bytes; neither working branch is changed. The initial integration harness incorrectly expected zero from a fixture explicitly declaring exit 1; the unchanged GNU control confirms exit 1, and the corrected selection passes. Both records are retained.
- Source archive matches all **1,174** committed files and executable modes. Delivered/rebuilt binaries pass linked-program execution; the independently downloaded binary also links/runs with no tools on PATH.

Download the binary/source archives and verify them with `sha256sum --ignore-missing -c SHA256SUMS`. `EVIDENCE_SHA256SUMS` additionally covers the notes, qualification and evidence assets. Copy `bin/fas-ld` from the binary archive to a directory on PATH. Runtime needs no OCaml installation or external linker; this binary requires Linux x86-64 and its recorded system libraries, including GLIBC symbols through **GLIBC_2.38**. System libraries are not bundled. Compiler/libc development files remain necessary when compiling hosted C programs.

The frozen contract is in `src/linker/SUPPORT.md` in the source archive. LTO, arbitrary GNU scripts, Windows, other architectures and unrestricted GNU compatibility are outside this release. Existing C++ exception/RTTI/lifecycle interoperability is retained without expanding its scope. Published upstream selections are bounded, not every configuration. Checksums are integrity records, not signatures. Internal OCaml modules remain source-version-coupled rather than a separately installed stable API.

Final fuzzing exposed a reproducible local TLS descriptor crash in the earlier candidate. Descriptor planning now validates that its canonical TLS definition has a retained section before creating its dynamic symbol. Local, hidden and internal definitions, metadata compatibility, checked GC rejection, output preservation and DTPOFF debug tombstones have permanent regression coverage. The original finding, failed hour and before/after replay evidence are retained. An initial overly broad guard failed the existing metadata regression; it was superseded and its incomplete/failed qualification remains retained. All complete gates above run on the narrower repaired source.

Earlier libarchive qualification hit three timestamp assertions. The same unmodified test independently reproduces those assertions with GNU-linked images; archive timestamps match actual files. That unchanged complete job passed on rerun. Original failed and replay evidence remain retained with no upstream-test change. The new complete matrix independently qualifies the final repaired source.

Earlier watchlist setup used filenames outside AFL's `id:` convention and imported zero seeds; those remain normal-corpus passes. A subsequent system suspend interrupted corrected seeded attempts; their duration checks correctly rejected them. The final campaigns use verified input hashes, temporary sleep inhibition and a full measured hour. Original records and the superseded runs are included in the evidence archive.

The qualification JSON, raw evidence, nine accepted hosted artifacts and the original failed libarchive artifact are retained here independently of expiring Actions artifacts. Performance optimization is the next workstream; no speed advantage over LLD is claimed. This release does not replace the Fas language's latest-release designation.
